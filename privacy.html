Data Security أمان البيانات

Your data is handled with care:

يتم التعامل مع بياناتك بعناية:

  • Passwords are hashed using bcrypt — they are never stored or readable in plain text.
  • All sessions are protected using JWT tokens with expiry.
  • Protected files are only served after token verification on every request.
  • Your data is stored on a secure MongoDB database and is not exposed to the public.
  • كلمات المرور مُجزَّأة باستخدام bcrypt — لا تُخزَّن أبدًا كنص قابل للقراءة.
  • جميع الجلسات محمية باستخدام رموز JWT منتهية الصلاحية.
  • الملفات المحمية لا تُقدَّم إلا بعد التحقق من الرمز في كل طلب.
  • تُخزَّن بياناتك في قاعدة بيانات MongoDB آمنة ولا تُكشَف للعموم.
